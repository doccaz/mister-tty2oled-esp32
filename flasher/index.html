How it works

  1. Hold the BOOT button on the board, plug it into this computer with a data-capable USB cable, then let go. (The browser usually can't reset these boards into download mode by itself; this step is what makes it connect.)
  2. Plug the CYD into this computer with a data-capable USB cable. Its USB-serial chip resets it into download mode automatically, so there is no BOOT button step. (If it ever fails to connect, hold BOOT while plugging in.)
  3. Pick your board above, press Connect and install, then choose the serial port (it shows up as "USB JTAG/serial debug unit"it shows up as a CH340 / "USB Serial" device).
  4. Wait for the flash to finish, then unplug and replug the board normally.
"Failed to initialize" or the port isn't listed? The board isn't in download mode: unplug it and repeat step 1 with BOOT held. Also close anything else using the port (serial monitors, the marquee web app) and make sure you picked "USB JTAG/serial debug unit", not another serial device.
"Failed to initialize" or the port isn't listed? Close anything else using the port (serial monitors, the marquee web app), try another data-capable USB cable, and pick the CH340 / "USB Serial" port. Some systems need the CH340 driver. If it still won't connect, hold BOOT while plugging the CYD in.

After flashing

  • With no saved WiFi, the display starts an open tty2oled-XXXX network with a setup page. Press the BOOT buttonTap the screen (or press BOOT) to show a QR code that joins it.
  • On the CYD, a tap also wakes the display, and the settings page has an option to follow the room light with the built-in light sensor. It shows the same round-native art, centred on the wider screen.
  • Manage the marquee art from the marquee web app over USB (WiFi works when you run the app locally, see the README).
  • Flashing keeps your saved WiFi and settings. When the installer asks, leave Erase device unticked; ticking it wipes them.
